# Contributing

PRs welcome. A good recipe has:

1. **A one-line law** — the invariant it protects (*"N items is one wait, not N waits"*).
2. **Measured numbers** — seconds, dollars, counts. Not "fast" or "cheap".
3. **A named gotcha** — the thing that silently cost someone money, and what it looked like.
4. **Where it stops** — what the recipe does *not* do.

Verify tool names against the live server (`flora_list_tools`) before submitting.
