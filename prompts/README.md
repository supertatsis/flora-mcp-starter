# Prompt library

Copy-paste prompts that work with FLORA over MCP. Each assumes the connector is on. All of them make the agent **quote in USD before spending**.

## Orientation (free)
- `List my FLORA workspaces and current balance. Don't generate anything.`
- `List image models with estimated cost per generation, cheapest first.`
- `What Techniques exist in my workspace, and what inputs does each need?`
- `What's on the canvas in my "<project name>" project, and what has it cost so far?`

## Images
- `One 1:1 image of <subject>, <lighting>, <lens>, <backdrop>. Quote, then run on approval.`
- `Three variations of the last image: warmer grade, cooler grade, higher contrast. Same composition.`
- `Reframe the last image to 9:16 and 16:9 without cropping the subject.`
- `Put this product photo on a clean white background.` *(runs a Technique)*

## Video
- `Animate this image into a 5 s clip, slow push-in, nothing added. Quote first.`
- `Resize this 16:9 video to 9:16 and 1:1 for Reels and feed, preserving the subject.`
- `Turn this script into a storyboard: shot list → keyframes → show me before animating anything.`

## Batch
- `Here are 12 SKUs [list]. One PDP hero each, identical studio setup, fire as one batch, quote the total.`
- `Take this campaign line and give me 8 localised versions, one per market, same art direction.`

## Refine
- `Judge the last result against the brief, name the single biggest defect, fix only that, re-run once.`

## Canvas housekeeping (free)
- `Arrange everything in this project in a tidy grid.`
- `Group the approved images into a field called "Finals".`
- `Share this project with a view-only link.`

## Prompt-writing tips that move the needle
1. **Subject, then light, then lens, then surface.** Models weight the start of the prompt.
2. **Say what must not appear** ("no props, no text, no hands").
3. **One reference image beats three adjectives** for brand consistency — upload it and ask the agent to use it.
4. **For batches, lock the style sentence** and vary only the subject line per item.
